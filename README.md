## About

Backend engineer and machine learning researcher with 4 years building production systems across healthcare, fintech, and real-time platforms. My core work is backend architecture and API design, and my research work is applied NLP, primarily low-resource language modelling. I have shipped end to end: REST APIs, mobile builds in Expo, and deployment on AWS EC2 and DigitalOcean.

Selected results:

- Built the backend and NLP pipeline for a clinical triage system reaching 93% answer accuracy, backed by 583+ documents indexed in Pinecone with sub-2-second retrieval under load.
- Reduced API latency by 42% on a real-time booking platform through query optimization, indexing, and a caching layer.
- Co-authored NLP research on low-resource African languages (Igbo, Bulu, Hausa, Swahili, and six others), outperforming NLLB-200 and OPUS-MT baselines; published in *Informatics* (MDPI).
- Built the payments microservice for a cross-border money-transfer platform, reducing failed transactions by 28% through fraud-detection rules.

Outside of client work, I build algorithmic trading systems in Python and MQL5, and study application security through structured penetration testing on my own projects.
